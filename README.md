# Porter Staff Website

Single-page staff travel tools (ZED lookup, fare calculator, My Trips, Travel Log, etc.) with **Express** for APIs and static hosting.

**Default product:** a **Vite-built SPA** served from **`vite-scaffold/dist/`** by **`server.js`**. Treat **`indexTEST.html`** as **legacy / dev fallback only** (in-browser Babel + CDN stack)—not what you ship to crew for production.

## Production deploy (recommended)

Ship (or build on the server) the **bundled client** before starting Node:

```bash
npm install
npm run build:client
npm start
```

Or one shot:

```bash
npm run start:prod
```

Open `http://127.0.0.1:3000/`. **`server.js` serves `vite-scaffold/dist/`** when **`vite-scaffold/dist/index.html`** exists and **`USE_VITE_DIST`** is not **`0`**. UI source of truth: **`vite-scaffold/src/porter-app.jsx`** (and **`vite-scaffold/src/lib/`** for My Trips widgets).

**Deploy checklist:** include **`vite-scaffold/dist/`** in your artifact (or run **`npm run build:client`** on the host). **GitHub Actions** runs **`npm run build:client`** before Playwright so automated tests match the same path as production.

## Local development

### Vite dev server + Express API (day-to-day)

Bundled SPA with HMR; Tailwind via PostCSS, React/Leaflet from npm (no Babel in the browser).

```bash
npm install
npm run sync:vite-public    # copy assets into vite-scaffold/public/
npm run dev:client          # Vite on http://127.0.0.1:5173 — proxies /api → :3000
```

In another terminal:

```bash
npm start
```

### Legacy: no client build (`indexTEST.html`)

If **`dist/`** is missing, **`npm start`** falls back to the monolithic **`indexTEST.html`** (React UMD + Babel standalone + Tailwind CDN). Use this for **quick experiments** or **emergency fallback**, not for production rollout.

### Keeping `indexTEST.html` aligned with Vite (only if you still touch the monolith)

**Workflow:** edit **`vite-scaffold/src/porter-app.jsx` first**; refresh the legacy file only when you must.

- **`npm run extract:porter-app`** — `indexTEST.html` → `vite-scaffold/src/porter-app.jsx` (overwrites Vite). Prefer editing Vite and syncing the monolith manually only if you still ship the HTML file. Optional: `python scripts/extract_porter_app.py path/to/compare.jsx` to diff without overwriting.
- **`npm run extract:vite-styles`** — `<style>` from `indexTEST.html` → `vite-scaffold/src/index.css` (overwrites).

My Trips modules: edit **`vite-scaffold/src/lib/`** first, then **`npm run sync:lib-to-js`** so **`js/`** stays aligned for the legacy HTML path.

## Deep links (hash routes)

After sign-in, the app syncs the URL hash with the current page (`#/calculator`, `#/mytrips_timeline?trip=…`, etc.).

## Internationalization

- English: `TRANSLATIONS.en` inside `vite-scaffold/src/porter-app.jsx` (**canonical**). A duplicate object exists in `indexTEST.html` only for the legacy monolith—edit Vite first, then sync if needed.
- French: `translations-fr.js` (`window.__TRANSLATIONS_FR`). Save as **UTF-8**. Vite `index.html` loads it from `/translations-fr.js` (copied into `vite-scaffold/public/` via `npm run sync:vite-public`).

## Service worker (PWA)

- **`CACHE_NAME`** in root `sw.js` (currently **`porter-travel-v13`**). Bump when you change precache or caching rules so clients drop old caches. **`npm run sync:vite-public`** copies root `sw.js` → `vite-scaffold/public/sw.js` — keep a single canonical file at the repo root.
- **Install** precaches stable files (`translations-fr.js`, `manifest.json`, `js/mytrips-timezones.js`, `/`, …), **best-effort** legacy URLs (`indexTEST.html`, Babel/React CDNs, `js/*.jsx`), then loads **`precache-manifest.json`** from the same origin when present (generated by `build:client` with the hashed **`/assets/*`** entry URLs).
- **Runtime** caching also fills the cache for same-origin JS/CSS/images and `/assets/*` (Vite chunks).
- Offline **navigation** falls back to `/`, then `index.html`, then `indexTEST.html` depending on what was cached.

## Security notes

- This project is intended as an **internal staff tool**. The admin modal password is still client-visible (`VITE_ADMIN_PASSWORD`). For **server backup pull/push**, prefer **`ADMIN_PASSWORD`** on Express (match the portal password) so **`POST /api/admin/login`** issues an **HttpOnly** cookie and you can omit **`VITE_ADMIN_API_TOKEN`** from production builds; **`ADMIN_API_TOKEN`** remains the HMAC secret for that cookie and optional **`Authorization: Bearer`** (e.g. CI).
- **CSP:** with **`vite-scaffold/dist`**, **`server.js`** enables a **strict** policy (fonts, Carto/Esri tiles, inline boot script in `index.html`). Set **`CSP_STRICT=0`** to disable. **Legacy** `indexTEST.html` mode keeps CSP off.

## Tech stack

- **Primary:** React 18, Vite 6, Tailwind 3 (PostCSS), Leaflet npm, split chunks — `vite-scaffold/src/porter-app.jsx`.
- **Legacy:** React UMD + Babel standalone + Tailwind CDN + `indexTEST.html` (fallback when `dist/` is absent or disabled).

## Environment

- `USE_VITE_DIST` — **default:** when **`vite-scaffold/dist/index.html`** exists, Express serves the **Vite `dist/`** app (production). Set **`USE_VITE_DIST=0`** only to force the **legacy `indexTEST.html`** stack (e.g. local debugging without a build).
- `TRUST_PROXY=1` — set when Express sits behind a reverse proxy so rate limiting uses real client IPs.
- `SOURCEMAP=1` — enable production sourcemaps in `vite build` (off by default for smaller deploys).
- `PLAYWRIGHT_BASE_URL` — e2e base URL (default `http://127.0.0.1:3000`).
- `PLAYWRIGHT_NO_SERVER=1` — do not auto-start `node server.js` during tests.

## Lib sync (My Trips)

- **`npm run sync:lib-to-js`** — copy `vite-scaffold/src/lib/*.jsx` → `js/` (canonical = Vite).
- **`npm run check:lib-sync`** — fail if copies drift (run in CI after `npm install`).
- **`npm run check:ci`** — `check:lib-sync` + `check:i18n` (requires Python for i18n).

## Travel log API (server hardening)

- `GET/PUT /api/travel-log` validate `employeeId` and cap list sizes; writes are **queued** and **atomic** (temp file + rename).
- Sensitive repo files (`travel-log-data.json`, `package.json`, etc.) are **not** served as static assets in legacy mode.
- `precache-manifest.json` is served with **`Cache-Control: no-store`** when using the Vite `dist/` build.
